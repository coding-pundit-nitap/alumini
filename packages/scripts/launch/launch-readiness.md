# Launch Readiness

**What this is:** the evidence for the launch decision. Each row is an acceptance box, a reliability check or gate, or a launch item. It cites the test, drill entry, file or owner action that proves it. `pnpm launch:check` resolves every reference:

- A test must be collected by a suite CI runs.
- A drill's newest entry must have passed within 35 days.
- Owner rows stay open until is ticked.

`pnpm launch:check --strict` exits 0 only when every row is proven. That is the launch gate.

Reference forms: `test:<path>#<test name>`, `drill:<file in packages/scripts/drills/reports>#<check>`, `doc:<path>#<text>`, `ci:<workflow>` (newest completed run on `main`), `owner:<OW-n>`.
